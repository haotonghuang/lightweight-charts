# ES 本地研究图表

基于本地 Lightweight Charts 5.2.1 的 ES 历史图表，提供 EMA_20、ADR_8、ABR_8、RTH K 线计数、逐根回放和早盘复盘。不需要 Python 第三方包、Node 构建或联网。

## 启动

```bash
cd /home/haotonghuang/projects/lightweight-charts
python3 es-research/server.py
```

等待 CSV 索引完成，在浏览器打开 <http://127.0.0.1:8765>。按 `Ctrl+C` 停止。端口被占用时使用 `--port 8766`。

默认数据已经独立复制到 `es-research/data/ES_1min.csv`，不再读取 `~/projects/backtrader/datas/ES_1min.csv`，也不会自动跟随源文件更新。约 388 MB 的 CSV 由 `data/.gitignore` 忽略，不随 Git 分发；此工作区已有副本。新机器需将同格式数据放到该路径，或用 `--csv /完整路径/ES_1min.csv` 指定。CSV 表头为 `,DateTime,Open,High,Low,Close,Volume`，时间格式为 `YYYY-MM-DD HH:MM:SS`，按时间升序排列。数据文件不会通过网页静态服务暴露。

## 使用

桌面界面按窗口高度铺满，顶部为紧凑工具栏和鼠标读数，图表自动占用剩余空间。指标开关位于“显示设置”，定义说明收在“说明”菜单；底部保留状态与署名。价格主图与范围副图默认高度比例为 7:1，可拖动面板分隔线调整。窄屏下控件换行、页面允许滚动。

- **历史浏览**：选择不超过 31 个自然日的区间、1 / 5 / 15 / 60 分钟周期，以及“仅 RTH”或“全部时段”，点击“加载图表”。默认是 5 分钟 RTH。滚轮缩放、拖动平移，十字光标查看 OHLC、成交量和指标；图表上方的读数条随鼠标同步显示 EMA20、ADR8、ABR8、K 线长度（H−L）、实体大小（|C−O|）及当天 RTH 跳空；移出图表后显示最后一根已显示 K 线的数值。
- **K 线回放**：选择开始和结束日期、周期、时段及起始日回放时间，点击“准备回放”。起点之前已收盘的 K 线作为背景，点击“下一根”或“播放”才显示下一根完整 K 线及对应指标。支持暂停、重置和 0.5–10 根/秒；图表获得键盘操作时可用空格播放/暂停、右箭头单步。切换设置或切到后台会暂停。起始时刻在一根 K 线内部时，该根留待首步播放，防止提前看到其后续价格。
- **早盘复盘**：选择日期并点击“加载早盘”，固定显示此前两个有 RTH 数据的交易日和当日 09:30–11:30 的前 24 个 5 分钟位置。当天首根 K 线默认位于图表水平中间，初始右半屏约容纳当日 24 根 K 线，左半屏显示约 24 根历史 K 线；前两交易日数据仍完整保留，可缩小或向左平移查看。缩放或平移后可用“开盘居中”恢复。周末、无 RTH 的日期会提示错误；历史不足或开盘时段缺 K 线会明确提示。

主图显示 K 线、EMA20 和成交量，下方面板显示 ADR8 / ABR8（单位：点）。各指标和 Bar Count 都可独立开关。回放时所有图形、指标读数和计数标记只使用已播放切片；这是一款本地练习工具，浏览器仍会预取所选区间数据，不提供防查看网络数据的考试模式。

## 阿布图表百科

工具行的“阿布图表百科”打开侧栏，与现有图表共用同一个页面和图表实例。Setup 类别承载背景与入场理由；跨类别复用的特性标签用于记录 `strong buying`、`just above EMA`、不利因素等。每个案例可以属于多个 setup，并添加多个标签和可选备注，无需填写真实成交或盈亏。

1. 收录案例后，可以直接在编辑区的“新建 setup”“新建标签”输入名称，点击“添加并选中”（或按回车）；创建后自动关联当前案例，同名选项直接复用，也会保留已写备注。“管理 setup 与标签”仍可用于预建、改名和编辑说明。仍被案例引用的条目不能删除，需先修改案例关联。
2. 在图表中点击一根 **RTH 信号 K 线**，核对工具行的 `YYYY-MM-DD bar N`，点击“收录信号 K 线”，选择 setup、标签后保存。这里的 bar N 指信号 K 线，而非之后实际触发或成交的 K 线。绘图工具激活时先切回“选择 / 拖动”。
3. 用 setup 下拉框、标签复选项筛选案例。多标签默认全部满足（AND），也可选择任一满足（OR）；搜索支持日期、bar 编号和备注。
4. 点击案例，或用“上一个 / 下一个”连续查看。现有图表会恢复该案例的周期、时段、价格口径，定位并高亮信号 K 线；筛选和列表滚动位置保留，不新开窗口。需要换日期时在原图加载；快速切换以最后一次选择为准。
5. 点击案例旁“编辑”修改关联、标签和备注或删除案例。新案例草稿的信号位置在收录时固定，继续查看其他行情不会悄悄改变它。

案例按实际时间戳定位，同时保存 bar 编号、数据文件名和估算去换月版本。源数据缺失、数据源不同或调整版本变化时会提示，避免错误跳转。正常查看可以看到后续行情；专门的隐藏答案练习模式和截图附件暂未加入。没有 RTH 编号的盘外 K 线及跨 RTH 边界的全部时段 60 分钟 K 线不支持收录。

百科自动保存在 `es-research/data/encyclopedia.sqlite3`，关闭或重启服务、清理浏览器存储不会删除案例。可用 `--encyclopedia-db /完整路径/百科.sqlite3` 指定其他位置；数据库由 Git 忽略，需自行备份。绘图仍使用原有浏览器存档，与百科记录独立。

“导出百科 JSON”包含全部 setup、标签、案例及关联；“恢复百科 JSON”会在确认后替换当前百科，并在事务中完整校验，失败时保留原记录。支持最大 64 MB 的 JSON 备份，导出时会检查同一限制；setup、标签、案例各最多 20,000 条，达到数量上限后仍可编辑已有记录。百科加载失败可点击“重试加载百科”，不影响行情查看。

## 画图与标注

工具行的“画图”提供四种工具：

| 工具 | 操作 |
| --- | --- |
| 趋势射线 | 依次点击两个锚点，默认向右延伸；Esc 退出绘图。已存趋势线加载后也按右射线显示，锚点保持原值。 |
| 支撑 / 阻力 | 点击放置水平线，在“绘图设置”填写文字可命名。 |
| 等距目标 | 依次选择 A、B、C，以 `C + (B − A)` 投射 100% 目标。 |
| 斐波那契回撤 | 依次选择波段起点和终点，显示回撤比例与价格。 |

普通落点和拖动端点会吸附到鼠标所指 K 线中屏幕距离较近的最高价或最低价，不取开盘价、收盘价或相邻 K 线。Shift / Ctrl 等绘图库原有临时自由选点操作仍可绕过吸附；右侧无 K 线的空白区保留自由投射。整体拖动图形时保持原几何结构。

在“绘图设置”的“回撤比例”中输入小数列表，例如 `0,0.382,0.5,0.618,1`（0.5 表示 50%），点击“应用回撤比例 / 设为默认”。支持负数和大于 1 的扩展位（范围 −10 至 10，最多 30 个）；配置保存在当前浏览器。若选中了一张斐波那契回撤图，会立即更新该图并可撤销；已有其他回撤图保持原比例。

使用“选择 / 拖动”模式选中图形后可拖动端点或整条图形。“绘图设置”中可修改颜色、线宽、标注，或删除选中图形。工具行的 ↶ / ↷ 撤销或重做；非输入框中可用 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z，Delete 删除选中图形。隐藏绘图不会删除数据。

绘图自动保存在当前浏览器的本地存储中。历史浏览和早盘复盘在相同周期、时段下共用标注；回放按周期、时段、起点日期与时刻分开保存。切换区间时，仍按时间和价格锚点恢复，而非绑定屏幕像素。回放只呈现当前已播放时刻可以使用的标注；重置后不会提前显示后面绘制或修改的答案。较晚时刻修改过的整张图形会隐藏到该编辑时刻，撤销该次修改可以恢复早先版本。清理浏览器存储或换浏览器不会保留这些数据，可通过“导出绘图 JSON”备份，再用“导入 JSON”恢复当前绘图范围。不要将 localStorage 当作唯一备份。

绘图使用本地固定的 `lightweight-charts-drawing@0.6.3`，MIT 许可与来源记录位于 `vendor/drawing`；没有启用平行通道或其余工具，也不依赖在线 CDN。

## 估算去换月与原始价格

价格选项默认“估算去换月”，也可选择“原始价格”加载对照。“换月记录”列出每个候选时刻、启用状态及调整点数。原 CSV 不会被改写。

当前文件没有合约代码或新旧合约同步报价，因此采用明确的启发式：只检查 3、6、9、12 月的 10–18 日、午夜 00:00–00:02、跨日相邻记录相隔不超过 5 分钟，且开盘相对上一分钟收盘的跳变达到 `max(2 点, 前收绝对值 × 0.2%)` 的位置。普通时段大跳空不自动删除。现有数据按此规则识别 37 处候选，累计差值 214.5 点；这不能证明它们都是换月，也可能漏掉较小价差或其它切换时刻。

调整使用差值回溯法：在每个候选点取 `delta = 新一根开盘 − 前一根收盘`，将该差值加到该边界之前的 O/H/L/C，多次换月向历史累加。最新一段保持原价，成交量不变；每根 K 线自身的长度和实体保持不变。分钟价格先调整再聚合，EMA、ADR、ABR 和 RTH 跳空统一使用当前选定价格口径。RTH 跳空依然是当前开盘减前一 RTH 收盘，真实的隔夜运动不会被一概归零。

[TradingView B-ADJ 官方说明](https://www.tradingview.com/support/solutions/43000685266-how-can-i-enable-backadjustment-for-continuous-futures/)使用新旧合约参考收盘差调整历史；本项目缺少两份合约报价，使用相邻分钟跳变估算，不能称为该算法的精确复刻。调整价回放使用完整文件的事后调整快照，绝对价位可能与当时实际交易价格不同；需要当时绝对价位时请选择原价。

原价模式沿用原有绘图存档。调整价按换月规则／记录的版本另存绘图，避免将旧绝对价位标注错误地搬到新价格上；修改换月修正记录后，旧版本标注仍保留在浏览器存储中，不会自动迁移。

需要更正候选时，可编辑项目内 `roll_overrides.json` 后重启服务并刷新页面，也可用 `--roll-overrides /路径/文件.json` 指定另一份。文件示例（以下为说明，不是当前配置）：

```json
{
  "version": 1,
  "events": {
    "2025-03-14 00:00:00": {"enabled": false, "note": "此点不作为换月处理"},
    "2024-06-14 00:00:00": {"enabled": true, "delta": 65, "note": "指定调整差值"}
  }
}
```

可以为文件中实际存在的时刻新增人工边界，但须同时提供 `delta` 与说明 `note`；不存在的时刻、无效数值或无效 JSON 会明确报错。当前默认配置为空覆盖表，使用上述自动规则。

只读审计命令：`python3 es-research/roll_adjustment.py scan --csv es-research/data/ES_1min.csv --overrides es-research/roll_overrides.json`。

## 日期切换性能

服务按需缓存每日聚合 K 线，重复或相邻日期查询可复用此前 80 个交易日的聚合结果；EMA／ABR 仍按原有预热窗口计算，缓存不包含未来行情或跨请求共享的指标状态。缓存按日期、周期、时段、价格口径和换月版本隔离，最多保留 200,000 根聚合 K 线及 1,024 个每日条目，超限时淘汰最近最少使用的条目。缓存只在当前服务进程内存在，重启后首次查询需要重新读取。

CSV 仍是唯一行情来源，无需转换 Parquet 或安装新依赖。服务还减少了盘外数据的日期解析，以及每根 K 线重复解析时间和扫描换月记录的工作。CSV 文件在运行期间变化时会提示重启服务重新索引，不会继续使用旧偏移和旧缓存；修改换月覆盖文件也需要重启。

可用 `python3 es-research/benchmark_dates.py --date 2017-03-14` 重现首次、重复和相邻日期的后端耗时测量。当前数据实测：优化前单日 5 分钟 RTH 查询约 1.8 秒，优化后首次约 0.53 秒、重复／相邻日期约 0.03–0.04 秒；实际速度取决于机器、周期、区间和缓存状态，不含浏览器渲染时间。

## 指标与时段

| 项目 | 定义 |
| --- | --- |
| EMA_20 | 收盘价指数平均，`EMA = (2/21) × close + (19/21) × previousEMA`，首个有效收盘价作为递推初值，参考 TradingView 当前 Pine `ta.ema`。 |
| ADR_8 | 此前 8 个有数据的已完成 RTH 交易日的 `daily high − daily low` 简单平均，不含当天，不足 8 日显示“—”。 |
| ABR_8 | 当前周期最近 8 根 K 线的 `high − low` 简单平均，包含当前已收盘 K 线；不是 ATR，不计跳空，不足 8 根显示“—”。 |
| Bar Count | 每个 RTH 日从开盘开始按周期位置编号，仅每第 3 根显示数字；5 分钟为 3、6、9…81。缺失位置不会让后续编号前移。 |

EMA / ABR 根据当前选择的时段连续计算，跨日不重置。在输出所选日期之前会读取最多 80 个历史数据日（仅 RTH 模式为实际 RTH 日）进行预热；足够历史下 EMA 初始化差异在显示精度内可忽略，最早数据处仍使用首收盘初值。ADR 从原始一分钟 RTH 日高低范围计算，与显示周期和所选区间无关。早盘复盘沿用 RTH 指标计算口径，再裁切可见数据。

时间按 CSV 原有的纽约本地墙上时间显示，不随浏览器时区变化，也不再做夏令时换算。按本次确认的口径，正常 RTH 共 405 分钟，即 81 根 5 分钟 K 线，最后一根标注 16:10。RTH 为工作日 **09:30（含）至 16:15（不含）**。RTH 聚合以 09:30 为锚点，60 分钟线为 09:30、10:30…15:30（末根最长 45 分钟）；全部时段按自然时钟边界聚合，跨 RTH 边界的 60 分钟线不提供 RTH 编号。聚合取首开、末收、极高、极低和成交量总和，不补造缺失分钟。

交易日来自源数据中存在 RTH 行的日期，不包含独立的交易所节假日或提前收市日历。提前收市按现有行计算，缺失分钟可能影响日范围和聚合结果，数据末尾不完整的时段也无法仅凭 CSV 判断。数据为历史快照，不自动更新；实际日期范围以启动提示为准。

每日 RTH 跳空采用 `当日 09:30 开盘价 − 前一个有 RTH 数据交易日的最后收盘价`，百分比为跳空点数除以前收。开盘上方显示小箭头及带正负号的点数，读数条显示鼠标所指日的跳空点数和百分比；可关闭标记。前收取源数据中前日 RTH 的最后记录（可能受缺失分钟或提前收市影响）。缺少准确 09:30 开盘或前日数据则显示“—”，不以较晚 K 线冒充开盘。回放只在开盘 K 线揭示后显示该日跳空。

## 定义来源

- [TradingView Pine Reference：ta.ema](https://www.tradingview.com/pine-script-reference/v6/#fun_ta.ema)：当前递推公式与首值规则。TradingView 的通用均线教程另有 SMA 初始化说明，本项目采用 Pine reference 口径，不保证与不同数据源/历史加载范围的 TradingView 图表逐点相同。
- [Tim Fairweather：Zen Trading Toolkit](https://zentradingtech.com/2026/04/24/zen-trading-toolkit-indicator-three-research-modules-one-indicator/) 和[公开 Pine 源码](https://github.com/Zen-Tim/zen-trading-tech-public/blob/main/indicators/Zen-Trading-Toolkit/zen-trading-toolkit-v1.8.2.pine)：ABR8 与已完成时段 ADR8 的定义。Tim 的 ES 预设是芝加哥 08:30–16:00，纽约时间对应 09:30–17:00；这里按用户确认的 09:30–16:15 计算，数值会与该预设不同。
- [Zen Bar Range Dynamics](https://zentradingtech.com/2025/07/19/how-to-research-bar-range-dynamics-using-zen-bar-range-category-v1/)：high-to-low 范围和 8 根回看说明。
